# 멜론 UX 맥락·정정 설계 메모

정리일: 2026-11-06 · 상태: 통합 목업의 구현 예정 범위 / 미구현·미검증

실행 기준은 [통합 목업 실행계획](멜론_UX_통합목업_장기계획.md)이다. V2·V3는 최종 구현 범위에 포함하며 게이트는 깊이만 조정한다. 파일 경로는 기존 연결을 유지하지만 이 문서의 V2·V3를 구현 제외 구상으로 취급하지 않는다.

## V2: 다차원 청취 맥락

함께 듣는 사람(혼자·친구·가족 등)과 활동(운전·업무·공부·운동·가사·휴식 등)을 독립 축으로 구분한다. 혼자 듣기도 항상 일반적인 취향을 뜻하지 않으며, 미선택 값을 혼자로 추정하지 않는다. 실제 그룹 구성원의 취향을 합치는 그룹 추천과 한 계정의 공동 청취 맥락은 구분한다.

기본 취향에 반영할 대상과 현재 추천을 고를 기준을 분리한다. 맥락별 선호를 보존하더라도 기본 취향에 자동 합산하지 않는다. 인적·활동 조합마다 별도 모델을 만들기 전에 단순 태그와 규칙의 가치를 검증한다. 여러 태그의 프로필을 합칠 때 동일 이벤트를 중복 가산하지 않는다.

V2는 공통 기반과 V1 다음에 구현한다. 게이트는 맥락 종류 수와 조합별 보정의 깊이를 정한다. 두 축의 작은 고정 선택지, 맥락별 프로필, 반영 대상·추천 기준의 독립 제어는 유지한다. V1의 사용성 성공만으로 맥락 모드의 가치를 증명했다고 하지 않는다.

## V3: 정정·가중치·추천 반응

- 지난 청취 세션의 맥락·학습 대상을 정정하고 원본·변경 이력을 보존한다. 실제 추천 모델의 즉각적인 역학습을 약속하지 않는다.
- 기본 취향 학습 가중치와 현재 추천 시점 가중치를 구분한다. 상황별 음악이 기본 취향에서 낮은 비중이어도 해당 활동에서는 우선 추천될 수 있다.
- 기본 취향은 보수적으로 표현하고, 여러 맥락을 모은 통합 요약은 별도 파생 뷰로 다룬다. 이를 객관적인 ‘진짜 취향’이라고 부르지 않는다.
- 한 곡 뒤 추천이 쏠렸다는 개인 경험을 다룰 때 장기 프로필 변화와 현재 추천 순위 변화를 구분한다. 실제 멜론 내부 원인은 확인되지 않았다.
- 가중치 0·결측·희소 맥락·중복·긴 청취 시간의 지배 문제를 정의한다. 수십 개 슬라이더는 사용자 부담부터 확인한다.

V3의 최소선은 지난 세션 1개에 대한 반영 대상·강도 정정, 미리보기·적용·복원, 유효 입력 재계산과 신규 청취 강도 설정이다. 임의 시간 범위·대량 정정·연속 슬라이더·정교한 최근 관심 제어는 깊이 조정 대상이다. 자동 상황 감지·차량 연동·그룹 추천·실제 ML·사용자 정의 무제한 맥락은 통합 목업 범위 밖이다.

아래는 2026-11-05 확인 기록이며 2026-11-06 현행 재확인 결과가 아니다.

- [Spotify 취향 프로필 제외 도움말](https://support.spotify.com/nz/article/exclude-playlists-or-tracks-from-your-taste-profile/): 곡·플레이리스트 제외와 영향 감소, 반영 지연·재생 출처 차이를 안내했다. 모든 신호 차단과 동일시하지 않는다.
- [Spotify Taste Profile 발표](https://newsroom.spotify.com/2026-09-23/taste-profile-shape-home-feed/): 국가·자격 조건이 있는 베타 안내다. 보편 제공·차별성 근거로 확대하지 않는다.
- [Apple 개인화 추천 안내](https://support.apple.com/en-asia/guide/iphone/iph2b1748696/ios): 당시 검색 결과만 확인했고 본문 재조회는 429로 실패했다. 상세 동작은 직접 확인 필요.
